## Что нового / What's new

- Ctrl+Tab: без «рамки в рамке». Браузер обводил выбранную миниатюру своей квадратной рамкой фокуса, а поверх рисовались наши — получалось три рамки. Теперь рамка фокуса браузера убрана, выделение одно.
- «Неон» в Ctrl+Tab переделан: одна светящаяся скруглённая рамка вокруг выбранной вкладки, лёгкая подсветка внутри, без лишних обводок у миниатюр; кнопка «Показать весь список» — неоновая «таблетка».

## Установка / Install

1. Скачайте **Hand-Design-v1.20.8.zip** ниже и распакуйте. / Download **Hand-Design-v1.20.8.zip** below and unzip.
2. Запустите **Setup.cmd**, выберите тему и браузеры, нажмите «Установить». / Run **Setup.cmd**, pick a theme and browsers, press Install.
3. Перезапустите браузер. / Restart the browser.

Уже стоит более старая версия — просто установите поверх, настройки сохранятся. / Already installed — just install over it, your settings are kept.

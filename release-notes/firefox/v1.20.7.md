## Что нового / What's new

- Ctrl+Tab больше не накладывается. Когда вкладки спрятаны и включено окно с превью, по Ctrl+Tab показывается только это окно — полоска вкладок больше не выезжает поверх него.
- Окно Ctrl+Tab без квадрата вокруг. Само окно теперь прозрачное и без системной тени, у содержимого есть место для тени и свечения — стиль «Неон» светится, а не упирается в прямоугольник. «Неон» ярче: светящаяся рамка у выбранной миниатюры.

## Установка / Install

1. Скачайте **Hand-Design-v1.20.7.zip** ниже и распакуйте. / Download **Hand-Design-v1.20.7.zip** below and unzip.
2. Запустите **Setup.cmd**, выберите тему и браузеры, нажмите «Установить». / Run **Setup.cmd**, pick a theme and browsers, press Install.
3. Перезапустите браузер. / Restart the browser.

Уже стоит более старая версия — просто установите поверх, настройки сохранятся. / Already installed — just install over it, your settings are kept.

## Что нового / What's new

- Меню без серых «ушей» по углам. На Windows 11 браузер подкладывал под каждое меню системный фон Mica — серый прямоугольник с маленькими скруглениями, и он торчал из-за круглых углов меню. Теперь подложка выключена (`widget.windows.mica.popups = 0`), окно меню прозрачное, видно только скругление темы. Полностью — после перезапуска браузера.

## Установка / Install

1. Скачайте **Hand-Design-v1.20.4.zip** ниже и распакуйте. / Download **Hand-Design-v1.20.4.zip** below and unzip.
2. Запустите **Setup.cmd**, выберите тему и браузеры, нажмите «Установить». / Run **Setup.cmd**, pick a theme and browsers, press Install.
3. Перезапустите браузер. / Restart the browser.

Уже стоит более старая версия — просто установите поверх, настройки сохранятся. / Already installed — just install over it, your settings are kept.

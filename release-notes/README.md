# Описания релизов / Release notes

Текст для страницы релиза на GitHub, по файлу на версию. Скопируйте содержимое файла в описание релиза.
Text for each GitHub release, one file per version. Paste the file's contents into the release description.

- [firefox/](firefox/) — Hand Design для Firefox, Floorp и форков. Новый файл делает `python firefox/tools/release_notes.py <версия>`.
- [chrome/](chrome/) — Hand Design для Chromium. Новый файл делает `python chrome/tools/release.py`.

## 0.1.2 — 2026-10-17
**Верх браузера красится сам.** Вкладки и адресная строка меняют цвет вместе с темой: без «Загрузить распакованное» и без перезапуска.
*English: Chrome, Brave and Chromium now paint the tab strip and address bar automatically whenever the theme changes — no more loading the frame folder by hand.*

### Добавлено
- Верх браузера в цвет темы — автоматически (Chrome, Brave, Chromium). У Chrome нет способа, чтобы расширение само меняло цвет рамки. Поэтому установщик ставит маленький помощник Hand Design, а расширение через него задаёт браузеру цвет темы (политика `BrowserThemeColor` в разделе текущего пользователя, без прав администратора). Цвет меняется сразу при смене темы или акцента. Браузер строит из него свою палитру, поэтому это оттенки акцента темы, а не точные цвета тема-пакета.
- Предупреждение при первом запуске. Из-за политики в меню Chrome появляется «Управляется вашей организацией». На новой вкладке один раз объясняется, что это только цвет, и есть кнопка «Выключить».
- Переключатель «Красить верх браузера» в Studio → Цвета. Если выключить, помощник уберёт политику, и надпись пропадёт.
- Кнопка «Покрасить рамку» в Chrome, Brave и Chromium больше не просит загружать папку: верх уже красится сам. Для Edge, Opera и Яндекса остаётся папка `frame`, как раньше.

### Исправлено
- Установщик показывал номер версии 0.1.0. Теперь номер берётся из файла `VERSION`.

**Важно для обновления:** помощник ставит установщик. Запустите `Setup.cmd` новой версии, затем нажмите ⟳ на карточке Hand Design на странице расширений.

## 0.1.1 — 2026-10-17
**Новая вкладка больше не нагружает видеокарту, вернулась история поиска.** Исправления по первым отзывам.
*English: the new tab no longer loads the GPU; search history, Gmail, Google apps and Chrome tools are back; Hand Design also opens at browser start and follows the browser language (switch in Studio); the clock colon no longer blinks.*

### Быстродействие
- Видеокарта больше не занята наполовину. Живые обои двигались CSS-анимацией на частоте монитора (144–240 кадров в секунду). Поверх них 11 «стеклянных» элементов каждый кадр заново размывали фон — на RTX 5070 это больше половины нагрузки. Теперь обои сдвигаются 20 раз в секунду (движение медленное, разницы не видно), а ярлыки под ними без размытия. Пока вкладка не на экране, ничего не считается.
- Размытие обоев включается, только если его выставили в Studio. Раньше пустой фильтр тоже стоил работы видеокарте.
- Островок Now Bar на сайтах больше не перерисовывает страницу. Эквалайзер и пульс звонка анимируются без перерисовки, «стекло» под островком убрано (он и так почти непрозрачный).

### Добавлено
- История поиска в строке поиска, как в Chrome. При щелчке видны недавние запросы (Google, Яндекс, Bing, DuckDuckGo, YouTube…). По мере ввода — подходящие прошлые запросы, сайты из истории и подсказки Google. Работают стрелки, Enter и Esc; крестиком запрос удаляется из истории. Подсказки Google выключаются в Studio. Расширению нужно новое разрешение «История».
- Панель сверху справа: Gmail, Картинки и меню ⋮⋮⋮. В меню — инструменты Chrome (история, загрузки, закладки, пароли, расширения, настройки, очистка истории, Studio) и приложения Google. Выключается в Studio → «Новая вкладка».
- Hand Design при запуске браузера. Стартовая Google или пустая вкладка сама заменяется на новую вкладку Hand Design. Раньше её было видно только по Ctrl+T. Выключается в Studio → «Новая вкладка» → «Открывать при запуске браузера».

### Исправлено
- Hand Design говорит на языке браузера. В 0.1.0 язык расширения брался из окна установщика, и при русском Chrome всё могло быть на английском. Теперь язык установщика — только для установщика, а расширение по умолчанию следует языку Chrome. При обновлении навязанный язык сбрасывается один раз.
- Переключатель языка в Studio (Цвета → «Язык / Language»): «Как в браузере», «Русский», «English». Раньше его не было вовсе.
- Двоеточие в часах больше не мигает.

## 0.1.0 — 2026-10-16
**Первая версия порта.** Основа — Hand Design 1.20.9 для Firefox (палитры тем те же и в 1.21.0).
*English: first release of the Chromium edition — 24 themes, new tab with wallpapers and clock, quick panel, Studio, Now Bar, call bar, tab previews, PDF viewer, Windows installer.*

### Добавлено
- 24 темы из тех же палитр, что в Firefox-версии. Генератор `tools/gen_chrome_themes.py` берёт их прямо из `firefox/tools/gen_themes.py`.
- Рамка браузера в цвет темы: 31 тема-пакет (у тем с двумя вариантами — светлый и тёмный).
- Новая вкладка: обои темы, 10 готовых или своя картинка, затемнение, размытие, живые обои. Часы в стиле темы (стеклянные в iOS), поиск поисковиком браузера, ярлыки сайтов.
- Быстрая панель «Дизайн» (кнопка расширения, Alt+Shift+D) и **Hand Design Studio** (Alt+Shift+S) с живым предпросмотром новой вкладки, готовыми наборами и сохранением настроек в файл.
- Now Bar и плашка звонка — «островок» сверху страницы. Музыка из другой вкладки: обложка, пауза, назад и вперёд. Звонок: таймер, микрофон и камера, Alt+Shift+M. Перетаскивается.
- Вкладки с превью (Alt+Q) в четырёх стилях: iOS, Windows 11, Список, Неон.
- Просмотрщик PDF на pdf.js: темы, тон страниц, рисование, надписи, маркер, поиск, сохранение с рисунками.
- Установщик (WPF, русский и английский): тема, обои, вариант, акцент, функции, поиск установленных браузеров, пошаговое подключение. `build-exe.bat` собирает один `.exe`.
- Vivaldi: CSS для всего интерфейса — опытная функция.

### Исправлено после первой проверки на Windows
- Установщик закрывался сразу после выбора языка. PowerShell отдавал окну цвет акцента в своей «обёртке», и окно падало при показе. Теперь элементы окна создаются напрямую.
- Ошибки установщика больше не молчат. Окно с текстом ошибки и номером строки, журнал `%TEMP%\HandDesign-Chromium-setup.log`, `Setup-debug.cmd` для запуска с видимой консолью.
- Понятное подключение в браузере. После установки — 7 шагов с указанием, где какая кнопка. Страница расширений открывается сама, а кнопка «Скопировать адрес страницы» поможет, если браузер её не открыл.
- Цвет акцента Windows читается правильно. Раньше подставлялся запасной синий.
- Now Bar не срабатывает на короткие и беззвучные звуки сайтов (была плашка «google.com»). Показывается только то, что играло со звуком дольше пары секунд. Без обложки — значок ноты вместо битой картинки.
- На тёмных обоях — тёмный вариант темы, даже когда Windows в светлом режиме. Часы, дата, поиск и ярлыки больше не выходят светлыми на тёмном (Material, One UI, iOS, macOS…). Исправлен подсчёт яркости цветов вида `color(srgb …)`.

Проверено в Chromium 141 (Linux, без окна) и на Windows 11 (установщик, Chrome).

**Известное:** полосу «Hand Design» внизу новой вкладки добавляет сам Chrome (с версии 138). Она скрывается правым щелчком по ней или в «Настроить Chrome».
